# 用海绵音乐生成（haimian.com，字节，免费、国内直接能用）

> 海绵没有公开的写法说明，下面是按界面和社区经验整理的，没有逐项实测。界面改版了以界面为准。

## 1. 选「自定义写歌」

- 歌词：贴下面整段（只留段落名，不要英文说明）。
- 曲风：选「说唱 / 嘻哈」，最多再加一个（比如「流行」）；选多了会打架。
- 音色：男声（想要女声就选女声）。
- 心情：选「轻松」「自信」这类，不要「悲伤」「抒情」。
- 如果有「参考音乐」：可以放一首你喜欢的、每分钟 {{bpm}} 拍左右的说唱，让速度更稳（可选）。

## 2. 歌词：整段复制

```
{{lyrics_plain}}
```

## 3. 挑选

1. 一次会出几版，先在网页上听。
2. 挑的时候看：开头前奏别太长（最好 5 秒以内就开始唱）；{{n_lines}} 句一句不少；口诀那两处听得清；不加歌词以外的字。
3. 下载 2–3 首 MP3，丢回给 AI：`mrv.py song <作品目录> --song 第一首.mp3 第二首.mp3`，它会自己量哪一首最合适。
4. 商用前先读海绵的服务协议：AI 生成音乐的版权归属要以协议为准。
