# 任何音乐模型都能用的写法

用哪家都行（Suno、海绵、Mureka、天工、网易天音、ElevenLabs……），把下面两样贴进它的「风格」和「歌词」框。
平台只认标签不认长句时，就从「中文说法」里挑几个标签选。

## 风格（英文，下面这串在 ElevenLabs 上实测过）

```
Chinese melodic rap, Mandarin sing-song chant, melodic rap on two notes, each line ends falling to the tonic, mid-high bright male voice, light autotune, tight quantized sixteenth-note flow, on-beat delivery, one lyric line per bar, {{bpm}} BPM, minor key, simple trap hi-hats, soft piano loop, clear diction
```

## 风格（中文说法）

说唱 / 嘻哈，男声，每分钟 {{bpm}} 拍，一句歌词正好一小节，像念口诀一样在两三个音上来回、句尾往下落，吐字一个一个清清楚楚，伴奏简单（鼓 + 钢琴），前奏不超过两小节，不要和声、不要 yeah 之类的垫词。

## 歌词：整段复制

```
{{lyrics_plain}}
```

## 我们实测出来的经验

- **旋律越强，吐字越糊。** 想好听就多出几版，挑口诀最清楚的那版，不挑最好听的。
- **同样的输入，结果不一样。** 实测 5 版里有 2 版人声晚进了两小节，后面全被挤。一次至少出 2–3 版。
- **节奏靠字数控制。** 平台大多不能指定「每句几秒」，一句一小节主要靠每句 11–15 个字。
- 生成完把 2–3 首 MP3 丢回给 AI：`mrv.py song <作品目录> --song 第一首.mp3 第二首.mp3`，它会自己量哪一首最合适。
