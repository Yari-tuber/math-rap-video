# 讲给别人听：原理、框架、不写代码的做法

用户想了解这类视频为什么有效、技术上怎么搭、怎么教别人做时，用这份材料回答。

## 一、为什么好记

三种记忆方式叠在一起，而且都跟着同一条音频走：

| 层 | 做法 | 作用 |
|---|---|---|
| **听觉：节奏和押韵** | 固定速度（约 90 BPM），一句歌词正好一小节，一韵到底 | 耳朵能预判下一句什么时候来。"顺口"就是这么来的，和背古诗、绕口令同一个道理 |
| **语言：口诀** | 8–10 个字，歌里出现 2–3 次，屏幕顶部一直挂着 | 把方法压缩成一句话；重复和常驻让它留在脑子里 |
| **视觉：图形演示** | 唱到哪个字，画面就走到哪一步；数字和图形同时出现 | 学生"看到"为什么对，而不是只背结论 |

叙事顺序固定：

1. **抛问题**：一条线上五个点，有几条线段？
2. **设陷阱**：挨个去连，越数越乱。先让学生体会笨办法不好用
3. **给口诀**：点数减一，连加到一
4. **示范**：5 个点 → 4+3+2+1=10；换成 6 个点 → 15
5. **讲原理**：第一个点往后连 4 条，第二个点连 3 条……往前的那条已经算过了
6. **收尾**：口诀再念一遍

**技术上只有一个关键点：所有东西都对齐到歌词的时间上。** 歌词按小节写，字幕按句切换，图形在唱到对应的字时出现，背景在句首换镜头。节奏感就是这么来的。

## 二、技术框架

```
① 口诀 + 歌词 + 分镜（AI 写，人确认）
        ↓
② 音频（客户自己做：AI 音乐平台 / 真人 / 配音）
        ↓
③ 算时间：识别字幕 → 对到歌词上 → 每句、每个字的时间 + 节拍
        ↓
④ 分镜表（口诀、公式、弹字何时出现）+ 本题图形 ── 时间都写成"第几句的哪个字"
        ↓
⑤ 逐帧画出叠加层 ──┐
⑥ 素材库按用途挑背景 ─┴→ ⑦ 合成成片
```

| 环节 | 本制作包里是什么 | 也可以换成 |
|---|---|---|
| 写词、分镜 | 任何大模型，按 `lyrics.md` 的规则 | — |
| 音频 | 客户自带 | Suno、海绵音乐、Mureka、天工、ElevenLabs Music；真人录音；TTS + 伴奏 |
| 识别字幕 | 任何能导出 SRT 的工具 | 剪映、Whisper 类工具、各家云端识别 |
| 算时间 | `prepare_audio.py` | 手工在剪映里对字幕 |
| 背景 | 自带素材库（AI 视频模型生成，按 9 种用途打标签） | 可灵、即梦、Veo、Runway 自己生成；实拍 |
| 图形动画 | Python 逐帧画（`overlay_engine.py` + 每题一个 `graphics.py`） | Manim（专做数学动画）、剪映关键帧、PPT 动画录屏 |
| 合成 | ffmpeg（`build_video.py`） | 剪映、Premiere、达芬奇 |

这套做法能稳定出片，靠的是三条设计：

1. **歌词定下来，其他都跟着歌词走。** 分镜里不写"第 28 秒"，而写"第 9 句唱到'四'的时候"。换一版音频，画面自动跟上
2. **通用的部分固定，题目专用的部分最小。** 横幅、字幕、公式、弹字、背景都是配置；每个新题目只写歌词、一张分镜表、一段画图代码
3. **每一步都有检查。** 音频有匹配率报告；分镜有 `check`；出片前有每句一格的预览图；出片后有总览图

## 三、不写代码的做法（剪映）

适合老师自己动手，2–3 小时一条。

1. 用 `lyrics.md` 末尾的提示词，让任意 AI 写口诀、歌词和分镜表
2. 用任意 AI 音乐平台生成歌曲：贴歌词（保留 `[Verse 1]` `[Hook]` `[Verse 2]`），风格写 `Chinese melodic rap, sing-song chant, 90 BPM, clear diction`。多生成几版，挑人声准时进、口诀听得清的
3. 背景：用素材库里的片段，或用可灵、即梦按 `library.md` 的提示词模板生成 6–8 段
4. 在剪映里：
   - 放歌，剪掉前奏，让人声一开头就进
   - 背景片段铺满时间轴，每两句换一段；整体调暗、降饱和、加暗角
   - "识别字幕"或"文稿匹配"生成逐句字幕：白字、半透明黑底、放底部
   - 顶部加口诀文字，从第一次唱到口诀起一直保留到结尾
   - 图形用 PPT 或画图软件做成透明底图片（每一步一张），在唱到对应那句时叠上去
   - 结果数字用黄色、放大
5. 导出前对照下面的清单检查

想让数学图形更精确，可以把第 4 步的图形换成 Manim 生成的透明底视频。

## 四、质量检查清单

- [ ] 人声一开头就进，没有长前奏
- [ ] 口诀每次出现都听得清
- [ ] 每句字幕和唱词同时出现
- [ ] 图形变化落在唱到对应数字或词的那一下
- [ ] 结果数字用黄色突出
- [ ] 背景足够暗，图形和字没有被吃掉
- [ ] 背景在句首换镜头，不在一句话中间换
- [ ] 数学内容正确（例题自己算一遍）

## 五、适合和不适合的题目

**适合**：方法能用一句口诀说清，原理能用图形演示。例如数线段 / 数角 / 数正方体、高斯求和、三角形内角和、圆面积、平方差公式、鸡兔同笼、植树问题。

**能做但要更长（约 2 分钟，分两三段）**：勾股定理的拼图证明、抽屉原理、等比数列求和。建议速度降到 75–80 BPM，每句 10–12 字，给看图留时间。

**不太适合**：大段代数推导、多步证明。每一步都需要停下来看，说唱的节奏会把人带跑。这类内容改用普通讲解配音（流程一样，音频换成讲解）。
