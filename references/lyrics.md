# 写口诀、歌词和分镜

## 口诀

- 8–10 个字，两个半句，最好押韵或对仗。例："点数减一，连加到一""爬高标层数，全加得总数"
- 口诀要直接给出**操作步骤**，不是结论。学生听完就能照做
- 写完自己用两三个例子验证，口诀对所有情况都成立（或者在歌词里说明适用范围）

## 歌词规则（为什么这样写）

| 规则 | 原因 |
|---|---|
| 90 BPM，一句 = 一小节 = 2.667 秒 | 一句正好一小节，听的人能预判下一句什么时候来；字幕、动画、背景切换也都能落在小节线上 |
| 每句 11–15 字；原理段 9–11 字 | 90 BPM 下一拍约 4 个字最舒服。原理段要留气口，否则结尾容易挤成一团、吐字变糊 |
| 一韵到底（i/ü、ang、ao 都好押） | 押韵叠在句尾音高回落的位置上，耳朵觉得顺 |
| 口诀第二次出现单独成 `[Hook]` 段（2 句） | 夹在长句里唱，口诀容易糊；单独成段并要求"慢、清楚"，能唱清楚 |
| 数字要能念顺，避免同音歧义 | "得到数字是四"会被唱成或听成"十四"，改成"五减一就等于四" |
| 避免整句都是数字堆叠 | "五四三二加一"可以，再长就唱不清 |

## 结构模板（24 句，约 64 秒）

```
## [Verse 1] 问题 + 口诀 + 例题（14 句）
1–2   抛问题：一个具体的图形 / 数字，问"有多少"
3–4   设陷阱：一个个去数，越数越乱、白费力气
5     转折：其实只需一个口诀
6     口诀本身 + "记住这 X 个字"
7     过渡：什么意思别着急
8–11  示范一：具体数字一步步代入，得出结果
12–13 示范二：换一个数字，更快得出结果
14    推广：再多也不慌，套口诀就行

## [Hook] 口诀（2 句）
15    口诀本身（只有口诀）
16    so easy / 比 X 还容易

## [Verse 2] 原理 + 收尾（8 句）
17    具体什么原理，看看这里
18–22 一步步讲为什么（每句对应画面上的一步）
23    所以……（回扣口诀）
24    下次遇到 XX，口诀记心里
```

`lyrics.md` 的格式（脚本按这个读）：

```markdown
## [Verse 1] 说明随便写
1. 一条线上五个点，排得整整齐齐
2. 问你一共几条线段，是不是有点迷
...
## [Hook] 口诀
15. 点数减一，连加到一
16. 是不是 so easy，比数手指还容易
## [Verse 2] 原理
17. ...
```

句子的编号就是分镜里 `L(6)`、`W(9,'四')` 用的句号，所以**歌词定稿后不要再增删句子**；要改字可以，改完检查分镜里用到的 `W()` 字还在不在。

交给客户做音频时，把编号去掉、保留段落标签，连同 `references/audio.md` 里的要求一起发。

## 分镜表

写在 `lyrics.md` 的末尾，单独一个 `## 分镜表` 小节（脚本不读它，只读前面带编号的歌词行）。它有两个用处：给用户确认画面思路；第 4 步写 `storyboard.json` 和 `graphics.py` 时照着做。

每句一行，写清楚画面动作和触发词。触发词就是唱到哪个字时画面变化，写分镜时直接变成 `W(句号,'字')`。

| 句 | 唱词 | 画面 | 触发 |
|---|---|---|---|
| 1 | 一条线上五个点 | 画线，5 个点每半拍弹出一个 | `L(1)+0.75` 起，每 `B/2` 一个 |
| 2 | 问你一共几条线段 | 右侧大字"=？" | `L(2)+0.6` |
| 9 | 然后从四往下加，四三二一 | A 连 4 条弧（先红后蓝），B 连 3 条……，下方出黄色计数，公式逐项出现 | `W(9,'四',2)` `W(9,'三')` `W(9,'二')` `W(9,'一')` |
| 10 | 加起来正好是十 | 公式出现黄色"= 10条" | `W(10,'十')` |

## 给其他 AI 用的提示词

```
你是一名会写说唱的数学老师。为下面的知识点写一首教学说唱，并给出分镜表。
知识点：【……】  年级：【……】
要求：
1. 先给一句 8–10 字的口诀，押韵、好记，直接说出操作步骤。
2. 90 BPM，每句歌词对应一小节，每句 11–15 字（讲原理的部分 9–11 字）。全篇押同一个韵。
3. 结构：[Verse 1] 14 句（问题 → 一个个数是陷阱 → 口诀 → 示范 → 换数字再示范 → 推广）；
   [Hook] 2 句（第一句只念口诀）；[Verse 2] 8 句（讲为什么口诀是对的 → 收尾）。
4. 数字要念得顺，避免同音歧义。所有例题自己验算。
5. 分镜表：每句歌词对应画面上的图形变化、弹出的字、公式写到哪一步，以及唱到哪个字时触发。
```
