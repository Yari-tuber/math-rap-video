# 常见问题

## 音频和时间

| 现象 | 原因 | 处理 |
|---|---|---|
| `prepare_audio` 报"歌词和识别结果只对上 x/y 个字" | 音频唱的不是这份歌词，或歌词文件拿错了 | 核对 `lyrics.md` 和音频是不是同一版 |
| 结论是"建议换一版" | 漏唱、人声晚进、整体被压缩、或多句对不上 | 换一版音频。不要硬用：漏唱的那句画面会一闪而过 |
| 某几句匹配率低于 50% | 那几句唱得糊，识别错得多 | 时间是按前后推算的，一般差 0.3 秒以内；请人听一下这几句。想更准就换逐字时间（`--words`）或换一版音频 |
| 人声比预期晚进很多，后面的句子被挤短 | AI 音乐平台的随机现象（实测 5 版里出现 2 次） | 换一版音频。所以让客户一次生成 2–3 版 |
| 口诀那句听不清 | 旋律强的唱法容易丢声调 | 请客户把口诀单独成段、唱慢；或换更偏"说"的风格 |
| 结尾几句挤在一起 | 原理段每句字数太多 | 歌词每句缩到 9–11 字后重新做音频 |
| 检测出的速度是 45 或 180 | 速度检测常差一倍 | 加 `--bpm 90` 这样的提示值 |
| 普通配音没有节拍 | — | 加 `--no-beat`；分镜里少用 `B`，多用 `L()` 和 `W()` |
| `librosa.beat.beat_track` 崩溃 / numba 报错 | 部分环境 numba 不兼容 | 脚本已避开这个函数；自己写分析代码时也不要调用它 |

## 分镜和渲染

| 现象 | 原因 | 处理 |
|---|---|---|
| `时间写法有问题 …：第 N 句「…」里找不到「字」` | `W()` 里的字不在那句歌词里（歌词改过，或写错句号） | 按提示改成那句里真实存在的字 |
| `check` 报"出现时间不在显示区间内" | 公式某一项的时间早于 show 或晚于 hide | 调整该项时间或 show / hide |
| 画面后半段不动 | 以前是叠加层中途出错而合成继续 | 现在 `build_video.py` 会报错退出；出片前先 `check` |
| `TypeError: 'float' object cannot be interpreted as an integer` | 直接用 PIL 画图时线宽给了小数 | 用 `ctx.stage()` 的方法画（自动取整），不要直接调 `ImageDraw` |
| 中文是方框，或报找不到字体 | 系统没有默认中文粗体 | `storyboard.json` 加 `"fonts": {"heavy": ["字体路径"], "subtitle": ["字体路径"]}`，或把字体文件放进 skill 的 `assets/fonts/` |
| 公式出现时位置偏左 | 公式按整条宽度居中、逐项显示 | 正常现象。想每一步都居中，就拆成多条公式 |
| 图形被字幕或公式压住 | 主图形画得太靠下 | 主图形控制在 y≈180–760；公式在 830，字幕在 1010。`check` 的版面提醒会指出时间点 |
| 图形飞行途中撞到横幅或别的图形 | 只看了每句一帧的总览 | 用 `frames <起> <止> 0.2` 把那段逐帧排开看；路线用 `ctx.along` 绕开 |
| 色块之间的细缝在成片里糊了 | 几像素的透明缝被视频压缩抹掉 | 缝宽 ≥ 8，或在色块下面垫一块深色底 |
| 半透明色块把下面的图形盖没了 | 以前的版本填充不混合 | 现在 `dot / rect / poly / wedge / tile` 的半透明填充会混合；线条仍然是覆盖 |
| 预览图里某一格是空的 | 那一句没有安排画面，或上一段已淡出、下一段还没开始 | 在 `graphics.py` 里检查那一句所在的时间段 |

## 背景

| 现象 | 原因 | 处理 |
|---|---|---|
| "找不到背景素材库" | 素材库还没安放 | 运行 `python scripts/install.py --library <素材库压缩包.zip>`；或解压到 skill 的 `assets/backgrounds/`；或设置 `MATH_RAP_LIBRARY`；或在分镜里写 `backgrounds.library` |
| "素材库里没有用途为…的片段" | 用途名写错，或库里这种用途没有片段 | `library_tool.py list` 看可用的用途和片段 |
| 提示"放慢较多" | 一段背景要撑的时间超过素材长度（约 8 秒） | 在 `plan` 里中间加一个切换点 |
| 背景太亮，字看不清 | 片段本身偏亮 | 把 `backgrounds.grade` 的 brightness 调低（如 -0.22），或换片段 |
| 背景里的人脸或亮处正好在文字后面 | 那一段没有题目图形（只有弹字或说明文字），所以没有自动换成安静片段 | 给那一句的用途加 `:quiet`，或直接写片段名；重跑 `bg` 和 `final` |
| 图形偏小、在手机上看不清 | 坐标和尺寸写得保守 | 按 `visuals.md` 第 1 节的尺寸参考放大；一排元素用 `ctx.spread(n)` 铺满宽度 |
| `check` 报"文字互相压住" | 两块文字的位置重叠（常见：嵌套的弧各标一个数字、说明文字和计数挤在一起） | 嵌套的弧只标最外层；把其中一块挪开或缩小字号；确实想叠在一起的可以不理 |
| 文字压在线条或色块上看不清 | `check` 查不出这种情况 | 看 `sheet --pages` 的大图，把文字挪到空白处，或给文字加 `stroke=3` |
| `check` 报两条公式"同时显示而且在同一行" | 下一条的 show 早于上一条的 hide | 让前一条先 hide，或给其中一条写不同的 `y` |
| 相邻两段是同一个片段 | 那种用途只有一段可选 | 给素材库加片段，或在 plan 里指定片段名 |

## 用 Google Flow 生成背景时（如果用它）

| 现象 | 处理 |
|---|---|
| 一次调用下载了好几个文件 | 工具把页面上的旧视频（甚至别的项目的）也下载了。按文件内容比对找出新的，并且**抽帧看过再入库** |
| 生成失败却返回了一个视频 | 返回的是页面上别的视频。耗时明显偏短（几十秒）时要怀疑 |
| 很快返回，文件只有几百 KB、打不开 | 还在渲染就返回了。删掉坏文件，等渲染完再取或重新生成 |
| 批量接口报代理超时 | 后台仍在逐段生成。改成一次生成一段 |
| 报"配置目录被另一个 Chrome 占用" | 后台无头浏览器卡住了。确认是带 `--headless` 的自动化进程后结束它，再重新连接 |
