# 数线段还在一条条连？八个字秒出答案！（v2 歌词，用于第 3 版起）

- 口诀：**点数减一，连加到一**
- 知识点：一条直线上有 n 个点，线段条数 = (n-1) + (n-2) + … + 1
- 套路：90 BPM，一句一小节（2.67 秒），一韵到底（i/ü 韵）
- 结构：前奏 2 小节 + Verse 1 共 14 小节 + Hook 2 小节（口诀单独念清楚）+ Verse 2 共 8 小节
- 相对 v1 的改动：第 8 句避免"是四"被听成"十四"；口诀第二次出现改成单独的 Hook 段；第二段每句缩到 9–11 字，留出气口

## [Verse 1] 问题 + 口诀 + 例题（14 句）

1. 一条线上五个点，排得整整齐齐
2. 问你一共几条线段，是不是有点迷
3. 一条一条挨个去连，数到怀疑自己
4. 漏掉一条多数一条，全都白费力气
5. 其实只需一个口诀，就能搞定这题
6. 点数减一，连加到一，记住这八个字
7. 什么意思别着急，我来慢慢讲给你
8. 五个点先减个一，五减一就等于四
9. 然后从四往下加，四三二一
10. 加起来正好是十，一条都不缺席
11. 整个过程三秒钟，一气呵成没问题
12. 换成六个点也行，五四三二加一
13. 一共十五条线段，算完都不费力
14. 再多的点也不慌，套用口诀就可以

## [Hook] 口诀（2 句）

15. 点数减一，连加到一
16. 是不是 so easy，比数手指还容易

## [Verse 2] 原理 + 收尾（8 句）

17. 具体什么原理，看看这里
18. 第一个点往后，连出四条去
19. 第二个点往后，三条到底
20. 往前那一条，刚刚算过去
21. 第三个点两条，第四个点一
22. 最后一个点，没有余地
23. 所以点数减一，加到一
24. 下次数线段，口诀记心里
